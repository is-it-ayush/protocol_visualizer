GOAL: UART and RS-232 encoders (shared async-serial framing) with parity and framing faults.
FILES: src/protocols/serial.ts (new), src/protocols/uart.ts (new), src/protocols/rs232.ts (new), src/protocols/index.ts (edit)
DO:
1. serial.ts: shared frame builder for config {baud, dataBits, parity:'none'|'even'|'odd', stopBits:1|2}: idle high, start 0, LSB-first data, optional parity, stop(s).
2. Field spans per frame on lane 'TX' (A to B) named start, data, parity, stop; node B replies on lane 'RX' with from 'B'.
3. Fault 'parity-error' flips the parity bit; 'framing-error' drives the first stop bit low; each emits an error event with kind = fault id.
4. Export uart: Protocol (id 'uart', digital lanes TX/RX, asciiInput true, faults parity-error and framing-error).
5. Export rs232: Protocol (id 'rs232', analog lanes, config adds voltage default 12; logic 1 = -voltage, 0 = +voltage, same faults, asciiInput true).
6. Register both in src/protocols/index.ts.
TEST:
```
npm test -- tests/uart.test.ts
npm run build
```
EXPECT: UART/RS-232 tests pass; build succeeds.
