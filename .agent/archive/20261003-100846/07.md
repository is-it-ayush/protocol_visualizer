GOAL: SPI encoder for all 4 modes with a CPOL/CPHA mode-mismatch fault.
FILES: src/protocols/spi.ts (new), src/protocols/index.ts (edit)
DO:
1. Export spi: Protocol (id 'spi'), config {mode:0|1|2|3, clockHz}, lanes CS, SCK, MOSI, MISO (digital).
2. CS idle high at t=0, asserted low for the transfer, released after; SCK idles at CPOL; MSB first.
3. MOSI/MISO change on the non-sampling edge and stay stable across the sampling edge (rising for modes 0,3; falling for 1,2); MOSI idles low after the last bit.
4. Emit one event kind 'sample' at each sampling edge time, and one 'rx' event per byte with value = byte the slave sampled.
5. MISO carries a slave reply byte per payload byte (from 'B'); field spans per byte on MOSI and MISO.
6. Fault 'mode-mismatch': slave samples on the opposite edge (sees the next bit), rx value corrupted, plus error event kind 'mode-mismatch'.
7. Register spi in src/protocols/index.ts.

```
npm test -- tests/spi.test.ts
npm run build
```
