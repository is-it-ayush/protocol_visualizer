GOAL: I2C write-transaction encoder with address-NACK and data-NACK faults.
FILES: src/protocols/i2c.ts (new), src/protocols/index.ts (edit)
DO:
1. Export i2c: Protocol (id 'i2c'), config {address (7-bit), read:boolean, clockHz}, lanes SCL and SDA.
2. Bit cell: SCL low first half, high second half; SDA changes only at cell start, except START (SDA falls while SCL high) and STOP (SDA rises while SCL high).
3. Field spans: start, address (7 bits MSB first), rw, ack (value 'ACK'|'NACK', from 'B'), data per byte, stop.
4. Fault 'address-nack': ack after address is NACK, no data, then stop; error event kind 'address-nack'.
5. Fault 'data-nack': first data byte NACKed, remaining bytes dropped, then stop; error event kind 'data-nack' with value = byte index 0.
6. Read mode (read:true): slave drives data bytes, master ACKs all but last; untested but must not crash.
7. Register i2c in src/protocols/index.ts.
TEST:
```
npm test -- tests/i2c.test.ts
npm run build
```
EXPECT: I2C tests pass; build succeeds.
