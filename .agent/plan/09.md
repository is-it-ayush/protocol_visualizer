GOAL: CAN 2.0A encoder with bit stuffing, CRC-15, ACK, and CRC-error / missing-ACK faults producing error frames.
FILES: src/protocols/can.ts (new), src/protocols/index.ts (edit)
DO:
1. Export canFrameBits(id:number, data:number[]): number[] = SOF, 11-bit ID, RTR, IDE, r0, 4-bit DLC, data, all MSB first, unstuffed.
2. Export crc15(bits:number[]): number (poly 0x4599, init 0) and stuffBits(bits:number[]): number[] (complement after 5 equal bits; stuff bit counts toward next run).
3. Export can: Protocol (id 'can'), config {id, bitrate}, single lane 'BUS' (dominant 0, recessive 1).
4. Stuff SOF through CRC; then CRC delimiter, ACK slot (dominant from 'B'), ACK delimiter, EOF; spans sof, id, rtr, ide, r0, dlc, data, crc, crc-delimiter, ack, ack-delimiter, eof.
5. Fault 'crc-error': receiver detects mismatch, emits error frame (6 dominant + 8 recessive, span 'error-frame') after ACK delimiter.
6. Fault 'ack-missing': ACK slot recessive, transmitter emits error frame after the ACK delimiter.
7. Each fault emits an error event (kind = fault id) and an event kind 'error-frame'.
8. Register can in src/protocols/index.ts.
TEST:
```
npm test -- tests/can.test.ts
npm run build
```
EXPECT: CAN tests pass; build succeeds.
