GOAL: LIN frame encoder with PID parity, classic/enhanced checksum, and checksum-error / no-response faults.
FILES: src/protocols/lin.ts (new), src/protocols/index.ts (edit)
DO:
1. Export linPid(id:number): number with P0 = ID0^ID1^ID2^ID4 (bit 6) and P1 = !(ID1^ID3^ID4^ID5) (bit 7).
2. Export linChecksum(data:number[], pid:number, model:'classic'|'enhanced'): number = inverted 8-bit sum with carry wrap (enhanced includes pid).
3. Export lin: Protocol (id 'lin'), config {id (0-63), checksum:'classic'|'enhanced', baud}, single lane 'LIN'.
4. Master header (from 'A'): break >= 13 dominant bits + delimiter, sync 0x55, pid; slave response (from 'B'): data bytes, checksum; bytes framed 8N1 LSB first.
5. Spans break, sync, pid, data (per byte), checksum; span value strings as '0x..' hex.
6. Fault 'checksum-error': wrong checksum on the wire plus error event; 'no-response': header only plus error event; kinds = fault ids.
7. Register lin in src/protocols/index.ts.
TEST:
```
npm test -- tests/lin.test.ts
npm run build
```
